The OpenGameArt page does not ship a separate licence file, so this note is the
licence record for the copy archived in this directory.

Status: the shipped stage 3 backdrop does NOT use these layers.  Reduced to the
game's 640x600 target they carry thousands of edge tones and cost ~18 kB of RLE
against a ~63 KiB firmware budget, so tools/build_stage_backgrounds.py draws a
broadleaf silhouette instead.  The pack stays in the repository on purpose: it
is the intended art for stage 3 if the firmware ever finds the room.

Before a public release, re-check the source page once.
