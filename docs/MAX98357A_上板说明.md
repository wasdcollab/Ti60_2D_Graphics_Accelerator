# MAX98357A 音频接线与上板说明

本文件是本工程的权威接线记录。此前的 AI 生成引脚建议不能直接使用：C5 / J7.32 在当前 Ti60F225 pinout 中标为 `GPIOL_11_PLLIN2`，是 PLL 时钟输入，不能作为 I2S 输出。

## 已实现的 FPGA 接口

| MAX98357A 信号 | FPGA 顶层端口 | FPGA 球位 | J7 | 说明 |
|---|---|---|---|---|
| BCLK | `audio_i2s_bclk` | A12 (`GPIOR_13`) | J7.40 | 3.125 MHz |
| LRC / LRCLK | `audio_i2s_lrclk` | A4 (`GPIOL_09`) | J7.34 | 48.828125 kHz，低为左声道 |
| DIN | `audio_i2s_din` | B5 (`GPIOL_10`) | J7.38 | 标准 I2S、16 bit、立体声 |

三个 GPIO 都是 3.3 V LVCMOS 普通输出。J7.37、J7.39 已为 I2C 占用，不能接 I2S。

## 实物接线

```text
MAX98357 VIN  -> 板卡 5 V
MAX98357 GND  -> 板卡 GND（与 FPGA 共地）
MAX98357 BCLK -> J7.40 / A12
MAX98357 LRC  -> J7.34 / A4
MAX98357 DIN  -> J7.38 / B5
MAX98357 SD   -> 一个确定的 3.3 V 电源点
MAX98357 GAIN -> 悬空（常见模块约 9 dB）或 GND（约 12 dB）
Speaker + / - -> 只接模块的 SPK+ / SPK-，不可把任一端接地
```

`SD` 不能悬空；它不是本次 FPGA 输出，因为其只需固定使能。不要把 SD 接 5 V，也不要把 5 V 接到任何 FPGA GPIO。若 J7.1 的 3.3 V 已被占用，请从板上的另一处确定的 3.3 V 电源点分接；接线前须以板卡原理图或丝印确认该点确为 3.3 V。

## 逻辑与验证

音频在 100 MHz `core_clk` 域生成。I2S 时钟采用整数分频，形成 3.125 MHz BCLK 和 48.828125 kHz 帧率；不需要 MCLK。`rtl/audio/i2s_tx.v` 遵循标准 I2S：LRCLK 跳变后的第一个 BCLK 为一位延迟，随后输出 MSB。

执行以下命令检查 RTL 帧格式：

```powershell
.\tools\sim_i2s_audio.ps1
```

固件通过 APB 地址 `0xF810004C` 向音频合成器发送事件。现有事件为普通射击、激光、击杀和 Boss 大招；背景音乐由 FPGA 内部的原创程序化旋律生成，不包含或分发任何东方原曲文件。

## 上板排查顺序

1. 先确认 VIN、GND、SD 的电源线，再接三根 I2S 信号线。
2. 下载已通过编译的 bitstream，确认 SD 为高电平后再上电功放。
3. 菜单和游戏开始后应有持续 BGM；普通射击、激光武器、击杀与 Boss 开场应有不同音色。
4. 无声时先量 VIN、SD，再以逻辑分析仪检查 BCLK、LRCLK、DIN；不要先交换扬声器或把扬声器负端接地。
